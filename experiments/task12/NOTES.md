# task12: Wire the reward into DiffusionNFT + smoke test (2026-11-17)

`make_nft_vp_env.sh` built the `nft-vp` env (copy of `nft` + omegaconf, kornia, pytlsd built from DeepLSD's submodule with CMAKE_POLICY_VERSION_MINIMUM=3.5, DeepLSD -e); `envs/setup_nft_vp.sh` is the from-scratch equivalent. Training prompts: `train_dl.py`, `prep_train.py` (1,927 never-used frames of SELECT scenes, 1,921 captioned), `make_dataset.py` (dataset/vp_hypersim train 1,921 / test 596). `lcbase.py` produced the per-prompt floor reference `lc_base.json` with the training-rollout sampler (2,517 prompts x 4). `repro_env.py` checked the single-env reward (fork-started pools deadlock after CUDA init, so forkserver). `run_smoke.sh`: 3-epoch sd3_vp smoke test on 4 GPUs (micro-batch 3 x 96 after the default 6 x 48 OOMed), exit 0, ~441 s/epoch, peak 44.6 GB/GPU; `check12.py` verified the logged reward parts against an offline re-score (exact except PickScore batch numerics, R max diff 0.0014). The DiffusionNFT edits are `rl/diffusionnft_vp.patch`. Outputs `$VP_DATA/outputs/task12/` (lcbase_all.csv, lcbase_imgs/, nft_logs/), `$VP_DATA/checkpoints/task12_smoke/`.

Scripts as run, with light fixes only: hardcoded paths replaced by `vp_reward.paths` (`DATA` = `$VP_DATA`, `code_dir(...)` for sibling code) / `config/env.sh`, and `vp_reward` imported as the installed package. Files: `check12.py`, `lcbase.py`, `make_dataset.py`, `make_nft_vp_env.sh`, `prep_train.py`, `repro_env.py`, `run_smoke.sh`, `train_dl.py`.
